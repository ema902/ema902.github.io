Pink Desktop Calculator

A Python desktop calculator I built in Cursor using Spec-Kit for spec-driven development. I wrote the requirements, specifications, design decisions, and implementation tasks before coding, then followed that workflow through implementation and testing.

I used Cursor’s AI-assisted tools to implement features, debug, and refine the code while staying aligned with those specs and tests. The calculator uses a custom recursive-descent parser instead of eval, with full expressions, implicit multiplication, percentages, powers, and trigonometric functions in degrees.

The calculation engine, session logic, and Tkinter interface are separate layers so the core can be tested with pytest, including test-driven development and handling of invalid or incomplete expressions.

Recipe Recommendation System

Python · PyGame · Graphs · Trees

An interactive recipe recommendation application that uses graph and tree-based data structures to organize recipe information and generate personalized recommendations. Users can search and filter recipes based on ingredients, dietary restrictions, excluded ingredients, and recipe categories through a custom PyGame interface.

I collaborated on this project in CSC111; it is not individual work.

Note: This project utilizes a subset of the Food.com dataset collected for academic research purposes. It is intended strictly as a proof-of-concept and is not licensed for commercial production use.
